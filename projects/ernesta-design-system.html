Ernesta Design System

A product system for a young company: foundations, components and page templates, built with engineering so design and code speak the same language.

I built Ernesta’s design system from the ground up: foundations, grid, and an extensive product system, working side by side with engineering to turn the library into a coded component system.

Foundations came first. The brand colors became a UI palette with clear roles for backgrounds, text, states and feedback, and one responsive type scale steps up from phone to desktop, so a single style name works at every breakpoint.

A nimble system of product cards, content blocks and page templates helped our small team build new pages quickly.

A foundational product system for a young company, and one shared language for design and engineering.
