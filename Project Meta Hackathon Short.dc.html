Internal Test Tools

Meta · Commerce Hackathon

Testing a simple order meant debug systems, custom scripts and cross-team coordination.

So I designed a dogfooding tool to create realistic test orders in a few taps.

Pick a path — happy, invalid tracking, late delivery — then move the order to its next state.

From workarounds to a few taps.

Engineers could reproduce and debug checkout, shipping and returns on demand.
